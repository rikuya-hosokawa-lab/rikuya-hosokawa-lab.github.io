# 京都府立医科大学 細川研究室 — 最終版

## GitHub Pages に公開
1. ZIPを展開し、すべてのHTML・style.css・site.js・favicon.svg・.nojekyllを同じ公開リポジトリのルートへアップロード。
2. Settings → Pages → Deploy from a branch → main / (root) → Save。
3. 公開URLで index.html が日本語トップ、en.html が英語トップ。研究紹介・業績・大学院進学・プライバシーの独立ページを含む。

## SEO・検索登録
公開URL確定後、Python 3で `python3 finalize_seo.py https://YOUR-NAME.github.io/YOUR-REPOSITORY/` を実行し、生成・更新されたHTML、sitemap.xml、robots.txtをアップロード。Google Search Consoleで所有権を確認し、サイトマップを送信。robots.txtはドメインルートにある場合のみ有効。検索掲載・順位は保証されない。

## 公開前の確認
- 研究理念、進学案内、職位・連絡先をご本人が確認。研究指導や学生受入れは大学の公式募集要項・指導体制に従う。
- 研究解説は公開本文・抄録等に基づく要約。原著の添付PDFおよび取得できた公開情報による点検を実施。未確認の論文・外部リンク等は別添の点検記録を参照。老衰死の地図は出典・CC BY 4.0を記載。装飾SVGは研究データではない。論文PDFは配布しない。
- 研究活動の写真は実物を用意し、写っている人の同意・権利確認後に追加。架空写真は使用しない。
- 新着情報の日付は確認できたオンライン公開日、または掲載年・巻号を記載。

## アクセス解析（公開後）
現在はアクセス解析・広告を組み込んでいません。必要なら Google Search Console で検索表示・クリックを把握できます。ページ別訪問数などは、公開後にプライバシー方針と大学の規程を確認し、例えば Cloudflare Web Analytics のアカウント・サイトを作り、発行された正規タグをHTMLに追加してください。利用条件・料金は導入時点に確認。導入した場合はプライバシー説明を更新してください。

## 更新
研究を追加するときは日英の研究ページ、研究一覧、業績一覧、必要に応じて新着情報を同時に更新。固定論文数は表示しない。公開URL確定後はSEOスクリプトを再実行。
